# ShopZ — E-Commerce App Wireframes

A mobile app wireframe project designed for a student-focused 
e-commerce shopping app, created as part of a UI/UX design assignment.

## Project Overview

**App type:** E-Commerce Shopping App  
**Target users:** Students aged 18–24  
**Tool used:** Figma  

---

## Screens Designed

| Screen | Description |
|--------|-------------|
| Screen 1 — Home |  Search bar, sale banner, category filters, Product grid |
| Screen 2 — Product Page | Image, price, colour swatches, size selector, add to cart |
| Screen 3 — Wishlist | Saved items with price drop and low stock badges |
| Screen 4 — Checkout | Order summary, address, coupon, payment, place order |

---

## User Persona

**Name:** Emma Myers
**Age:** 21  
**Occupation:** 3rd year Commerce student, Kerala  
**Goals:** Find trendy items at student-friendly prices  
**Pain points:** No clear student discounts, confusing return policy  

---

## Design Decisions

- Wishlist is a main tab — students save items and buy later during sales
- Student coupon field is at the top of checkout — not hidden
- Price dropped and Low stock badges create urgency
